# 🔧 Oficina Mecânica — Landing Page Demonstrativa

Uma landing page rápida, profissional e focada em conversão para oficinas mecânicas, auto centers e prestadores de serviços automotivos.

🔗 **[Clique aqui para ver a demonstração ao vivo](https://modelo-oficina.vercel.app)**

---

## 🎯 Funcionalidades Principais
- **Design Responsivo:** Adaptado para telemóveis, tablets e computadores.
- **Botão de WhatsApp Direto:** Facilita a solicitação de orçamentos rápidos e socorro mecânico.
- **Exibição de Serviços:** Destaque para manutenção, revisão preventiva e diagnósticos.
- **Localização e Contato:** Informações claras sobre endereço e horário de funcionamento.

## 🛠️ Tecnologias Utilizadas
- **HTML5:** Estrutura semântica.
- **CSS3:** Estilização moderna e layout responsivo.
- **Vercel:** Hospedagem e deploy contínuo.
